# Мій склад

Приймання й відвантаження посилок. Працює повністю на телефоні, без сервера й акаунтів. Версія 2026.11.05-2100.

## Що в папці

| Файл | Призначення |
|---|---|
| `index.html` | увесь застосунок: інтерфейс, логіка обліку, стилі |
| `sw.js` | service worker: робота без інтернету й оновлення |
| `manifest.webmanifest`, `icons/` | встановлення на головний екран |

Сторонніх бібліотек, аналітики й запитів до чужих серверів немає. Дані зберігаються в IndexedDB браузера на конкретному пристрої.

## Як розмістити (потрібен HTTPS)

Будь-який статичний хостинг підходить. Найпростіше — GitHub Pages:

1. Створіть репозиторій на github.com (можна приватний, якщо тариф дозволяє Pages для приватних).
2. Завантажте **вміст** цієї папки в корінь репозиторію (Add file → Upload files).
3. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/ (root)` → Save.
4. Через хвилину-дві з’явиться адреса виду `https://<логін>.github.io/<репозиторій>/`.

У коді немає ваших даних — лише порожній застосунок, тому публічний репозиторій нічого не розкриває.

Підійдуть і Cloudflare Pages, Netlify чи власний сервер: просто віддайте цю папку як статичні файли.

Перевірити на комп’ютері без хостингу:

```
cd miy-sklad
python3 -m http.server 8080
# відкрийте http://localhost:8080
```

## Встановлення на iPhone

1. Відкрийте адресу застосунку в **Safari**.
2. Кнопка «Поділитися» → **«На початковий екран»** → «Додати».
3. Запускайте з іконки «Мій склад». Застосунок відкривається на весь екран і працює без інтернету.

Важливо: встановлений на головний екран застосунок зберігає дані надійніше. Звичайну вкладку Safari може очистити, якщо сайтом довго не користуватися.

## Резервні копії

Налаштування → «Зберегти копію» створює файл `.json` з усіма посилками й історією. На iPhone відкриється меню «Поділитися» — збережіть у «Файли» або надішліть собі. «Відновити з файлу» перевіряє структуру й попереджає перед заміною даних. Застосунок нагадає про копію, якщо її не робили понад 7 днів.

## Оновлення

Замініть файли на хостингу новими. Відкритий застосунок покаже «Доступна нова версія» → «Оновити». Дані складу не зачіпаються: вони окремо від файлів програми.

## Як працювати

**1. Підвоз → вкладка «Підвоз».**

* Угорі «змінити»: дата підвозу й маршрут (`04.11 · РЗ -> Федекс`). Дата стає датою посилок.
* Виберіть позицію (Пегас, Тор…) або «+ Нова», «Як минулого разу» — додати всі позиції з попереднього підвозу.
* Біля позиції «+» → поле номера (звичайна цифрова клавіатура) і поле вмісту.
  * Номер → Enter — записано. Вміст запам’ятовується, тож сім «паливо» поспіль — це просто сім номерів і Enter.
  * Інший вміст — набрати номер і натиснути кнопку вмісту (вода, бк…) або вписати свій.
  * Без номера — товар: «Бк - 4 цинка», «Генератор».
  * ⚠ — проблемна посилка (для фото).
* Номери записуються в будь-якому порядку — в картці вони одразу стоять по порядку. Повтор номера чи посилка, що вже є на складі, підсвічуються червоним. Натисніть записану, щоб виправити чи прибрати.
* Чернетка зберігається, навіть якщо закрити застосунок.

«Готово» → перевірка → «Зберегти й скопіювати». Текст для начальника, вже посортований:

```
04.11 РЗ -> Федекс

*Пегас*
1 - стяжки бананка
4 - газ
13 - паливо
14 - паливо

*Атлас*
Бензин 2 каністри
Бк - 4 цинка
```

Готовий список з месенджера (у тому ж форматі, навіть невпорядкований) можна вставити через «Вставити готовий текст».

Далі на екрані підвозу — «Додати фото» → «Надіслати» (фото йдуть разом із текстом, у застосунку не зберігаються).

**2. Загрузка → вкладка «Склад».** Натискайте посилки, що їдуть (або «Усі» / «вибрати всі» для групи чи дати), далі «Список». Текст для начальника:

```
Манчестер:
3.11 - 1, 3, 4, 6

Вінтерс:
3.11 - 2, 5, 8, 9
```

`3.11` — дата пакування з ярлика. «Скопіювати й списати» кладе текст у буфер і прибирає ці посилки із залишку. На складі лишається решта.

**3. Історія.** Усі прийоми й загрузки: можна ще раз скопіювати текст, повернути загрузку на склад або видалити помилковий прийом. Будь-яку дію також можна скасувати кнопкою «Скасувати» одразу після неї.

Утримання посилки на складі відкриває картку: номер, вміст, дата пакування, позиція, позначка ⚠, примітка, видалення.

Посилку визначають позиція, дата й номер. Повтори не блокуються (на ярликах буває однаковий номер з різних днів), але підсвічуються, щоб їх перевірити.

## Перехід зі старої версії

Дані попередньої версії (з місіями) переносяться автоматично: посилки з номерами — як є, товари — як посилки без номера з описом «Вода 10 паків». Місії не переносяться, але зберігаються в резервній копії.
